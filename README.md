Apartments Portfolio

This project presents a collection of SQL queries focused on real estate data analysis using Microsoft SQL Server.  
The goal was to demonstrate practical data exploration and reporting skills using relational data from multiple connected tables.

The dataset represents apartment listings across various Polish cities, containing details about price, size, facilities, building year, materials, and distance from city centers.

The queries aim to explore and summarize the data by:
- Listing all cities and available apartments  
- Counting apartments per city with average price calculation  
- Identifying the largest apartments in each city  
- Showing minimum, maximum, and percentage price differences  
- Filtering apartments by amenities (parking, security, elevator)  
- Selecting top 5 most expensive apartments per city  
- Finding apartments within specific price and location ranges  
- Creating analytical views (`VIEW`) and summary queries (`CTE`)

 SQL Concepts Demonstrated

- Data aggregation – `COUNT`, `AVG`, `MIN`, `MAX`, `ROUND`  
- Conditional logic – `CASE WHEN`  
- Joins – combining multiple tables 
- Subqueries – filtering and comparison using nested queries  
- CTEs (Common Table Expressions) – building reusable analytical queries  
- Views – consolidating multiple datasets into one logical view
